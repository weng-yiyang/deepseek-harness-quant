# 分钟数据接入说明

> 分钟数据（A股 1 分钟、期货分钟）由用户自行获取，数据就位后系统自动解析入库。

## 一、使用流程

1. 将分钟数据放入 `data/minute/download/`（任意格式、嵌套目录均可）
2. 运行 `python data/ingest_minute.py --scan`（或接入每日自动调度）——自动解析（列名/编码/压缩包格式自适应）并入库 `minute.db`
3. `python data/ingest_minute.py --status` 查看入库进度

## 二、入库规范

```
minute.db
├── minute_1m(code TEXT, trade_time TEXT, open/high/low/close REAL,
│             volume REAL, amount REAL, source TEXT,
│             PRIMARY KEY(code, trade_time))        -- 主键防重复
└── bar_meta(source, code, start_time, end_time, rows, updated_at)
```

- **source**：`a_share`（带 .SZ/.SH 后缀） / `futures`（品种+合约，如 rb2610）
- **格式自适应**：自动探测列名（time/trade_time、vol/volume、ts_code/symbol/code 等），支持 .csv/.txt/.csv.gz；单股票文件无 code 列时用文件名推断
- **重复入库安全**：INSERT OR REPLACE，重跑不产生重复
