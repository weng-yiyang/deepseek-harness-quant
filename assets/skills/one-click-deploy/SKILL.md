# 一键部署向导（v1.0）

> 定位：**新用户的"上手指引员"**。用户下载开源包、拿到 AI API 后，本向导一步一步问清楚必需的东西，把系统配置到"能查数据、能看板、能跑通验证"的程度。
> 铁律：**只问必需项；每步一个主题；用户提供了才继续；绝不为用户编造凭据或数据；所有敏感信息只写本地配置文件，绝不打印回显。**

## 〇、部署前检查（第 0 步，自动执行不问用户）

1. 确认 Python ≥ 3.11：`python --version`
2. 确认依赖可装：`pip install -r requirements.txt`（失败则给出系统级提示）
3. 确认目录结构完整：`config/`、`data/`、`deck/`、`harness/` 存在（包根目录）
4. 汇报检查结果 → 进入第 1 步

## 一、分步引导流程（严格按序，一步一问）

### 第 1 步 · AI API（问用户要：API 凭据）
- **问**：你的 AI API 是哪个平台？（选项：DeepSeek 官方 / 其他兼容 OpenAI 格式 / 暂不接入先用演示模式）
- **要**：API Key + Base URL（如 `https://api.deepseek.com`）+ 模型名（如 `deepseek-chat`）
- **做**：写入本地配置（`harness/home/.credentials.yaml` 或平台配置位，600 权限意识），**回显只显示 key 尾 4 位**
- 说明：演示模式可跳过，系统仍可用合成数据跑通看板

### 第 2 步 · 行情数据源（问用户要：数据获取方式）
- **问**：行情数据想怎么接入？
  1. **Tushare**（需要 token，覆盖最全，推荐）→ 要 token（注意：部分接口需积分）
  2. **AKShare**（免费开源，免 token，覆盖基础日线）→ 无需凭据
  3. **演示数据**（包内合成样例，立即可用，用于跑通流程）→ 无需凭据
- **做**：把选择写入 `config/params.yaml` 的数据源段；提示数据边界（免费接口的覆盖限制）

### 第 3 步 · 配置落盘（自动）
- 把第 1-2 步的答案落盘到用户配置区（不覆盖 `.example` 模板）
- 生成 `.gitignore` 排除确认（key/数据不入库）
- 展示"已保存哪些配置、保存在哪"

### 第 4 步 · 拉取数据（执行，可后台）
- 按所选数据源运行对应获取脚本（如 `data/fetcher_akshare.py` / `data/fetcher_tushare.py`）
- 演示模式：运行演示数据生成脚本
- 过程中回报进度；失败则诊断（token 无效？网络？积分不足？）并**回到对应步骤重问**

### 第 5 步 · 全链验证（自动验收）
跑通最小闭环并逐项回报：
1. 数据文件存在且非空 ✅/❌
2. 看板服务能启动（`deck_server.py`）并返回 200 ✅/❌
3. 因子计算能跑（至少 1 个演示因子）✅/❌
4. 生成验证报告（写入 `logs/deploy_report.md`）

### 第 6 步 · 完成汇报
- 汇总：接入了什么 / 数据覆盖范围 / 下一步建议（配置每日自动更新、接 HARNESS 桥等）
- 明确告知：**这只是部署完成，不构成投资建议；数据边界（第三方数据仅自用）**

## 二、边界（向导必须遵守）

1. **不碰用户隐私**：key 只写配置文件，不发送到任何第三方，不写入日志/报告
2. **数据禁再分发**：用户数据只进本地库；开源包不含真实行情
3. **不夸大**：免费数据源的覆盖限制要明说（如换手率历史缺失、分钟数据需另购）
4. **可中断续跑**：任何一步失败都可从该步重来，不损坏已完成配置
5. **中文友好**：全部提问用中文，术语首次出现给解释

## 三、提问模板（每步一句话，附选项，等答案）

```
【第 X 步 / 共 6 步】<主题>
需要您提供：<具体要什么>
选项/示例：<可选项或示例值>
（跳过/兜底：<跳过方式和后果>）
```

## 四、开源包路径约定（用户环境，相对包根目录）

- 配置模板：`config/*.example` → 复制为 `config/*` 后填写
- 数据目录：`data/cache/`（gitignore 保护）；凭据：`harness/home/.credentials.yaml`
- 看板：`deck/deck_server.py`（默认 8787）；启动器：根目录 `start.bat`（如有）
- 部署报告：`logs/deploy_report.md`
