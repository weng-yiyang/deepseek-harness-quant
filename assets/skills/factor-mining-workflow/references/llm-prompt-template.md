# LLM 生成提示模板（融合工作流 P2 用）

> 实测校准：统一**逆波兰式**输出；可读前缀式仅展示。前缀/后缀混用会导致全部候选判非法（2026-08-15 实测 19/19 失败）。

## 模板（Phase 2-B 直接用）

```
你是因子挖掘助手。用以下公式语言生成 alpha 候选。

【特征（叶子，符号化）】
{FEATURES}   ← 从工作区 _factor_single 可算的因子里选 6-16 个，含 *_rel（行业内相对）

【算子（内部节点，符号化）】
ADD(2) SUB(2) MUL(2) DIV(2) NEG(1) ABS(1) SIGN(1) GATE(3) JUMP(1) DECAY(1)
DELAY1(1) MAX3(1) DELTA5(1) MA20(1) STD20(1) TS_RANK20(1)   ← 括号内是 arity

【语法（必须遵守）】
1. 每条公式 = 逆波兰 token 序列，长度 ≤ 8（A股版）或 ≤ 12（主流程）。
2. 逆波兰求值：遇特征压栈；遇算子弹出 arity 个操作数，计算后压回；终栈必须恰好 1 个值。
3. 合法性自检：叶子数量 = Σ(arity-1) + 1。
4. 输出只给逆波兰序列；可读前缀式（如 STD20(x)）仅用于注释，绝不出现在 formula 行。

【约束】
1. 目标：预测未来 N 日收益的截面排序能力，机制需可解释（一句话经济逻辑）。
2. 避免：常量因子（std<1e-4）、未来函数、与池内锚点高度同构的公式（锚点：reversal20
   sentiment turnover lowvol amihud turn_std20 turn_mid_prox；相关 >0.5 会被去重闸门淘汰）。
3. 已覆盖赛道（上轮被淘汰的同构项）提示：{COVERED} ← 换思路，不要重复。
4. 若目标是行业域：优先使用 *_rel 行业内相对特征（行业 beta 会主导绝对量价特征）。

【输出格式】（每条约 4 行，严格）
formula: [token1, token2, ...]
可读: 前缀式（仅注释用）
机制: 一句话经济逻辑
自评: ICIR@20 区间（须诚实，0.0-0.6）

现在生成 20 条，主题：{用户主题} ｜ 目标域：{DOMAIN} ｜ 持有期：{HORIZON}
```

## 校验-重试闭环（P2 必做，论文实证 10 条仅 4 条正确）

1. 正则/栈模拟语法校验（见 code-skeletons.md `validate()`）
2. mock 数据执行语义校验（抓 log(0)/sqrt(-5)/单位不兼容/常量）
3. 非法项：带报错信息构造 retry prompt → 重生成（上限 τ=3）
4. 合法项并入下一轮 prompt 历史（防重复生成同一批）

## 覆盖反馈（去重闸门联动）

被去重闸门淘汰的同构项 → 归纳为"已覆盖赛道" → 填入下轮 {COVERED}。
例：`ABS(ADD(sentiment,sentiment))` 与 sentiment 相关 1.000 → 提示"情绪族已覆盖，换量价关系/波动结构赛道"。
