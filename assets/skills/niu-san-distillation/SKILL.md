# 牛散蒸馏方法论（总览版 v1.0）

> **核心立场（必须先读）**：牛散/游资分析有三重风险——①信息滞后（持仓/席位披露有 T+1~季频延迟）；②"造神"炒作（媒体/交易软件放大效应，实证有利益链调查）；③幸存者偏差（被记住的都是赢家）。本 skill 的用途是**蒸馏可验证的行为模式**，不是跟随买入。
> 与本工作区铁律一致：**任何牛散信号进组合层前必须过验证链**（截面 ICIR 只是门票）。

## 一、牛散分类框架（先分类再分析）

| 类型 | 代表 | 核心特征 | 可转因子方向 |
|---|---|---|---|
| **价值牛散/私募** | 林园、冯柳（高毅）| 长线、集中、行业偏好（消费医药）、重仓披露（季频）| 质量/垄断/行业配置因子 |
| **游资席位（连板/打板）** | 陈小群（银河大连黄河路）、赵老哥、章盟主 | 短线、题材、龙虎榜席位、人气接力 | 龙虎榜因子（lhb_jg_cnt 已有）、涨停族 |
| **游资席位（低吸/半路）** | 炒股养家等 | 情绪周期、分歧转一致 | 情绪因子（sentiment 已有）|
| **机构/北向类** | 社保、QFII、北向 | 配置型、低频 | institution 族（已有）|

## 二、分析流程（5 步）

### Step 1 定身份与数据源
- 确认对象类型（价值/游资/机构）+ 可核实数据源（龙虎榜席位 / 季报前十大流通股东 / 股东户数 / 公开访谈）
- ⚠️ 验证信息可信度：一手（交易所/公司公告/官方访谈）> 媒体 > 社区；**道听途说不采信**

### Step 2 行为画像（决策蒸馏）
- 收集：龙虎榜买入记录（席位+日期+金额+股票）、重仓披露（季度）、公开言论（有出处的语录）
- 蒸馏出：偏好行业/市值/风格 + 择时习惯 + 仓位纪律
- 输出：行为特征表（特征 → 证据 → 时间窗口）

### Step 3 转因子假设（关键一步）
- 把行为特征翻译成**可计算假设**，如：
  - 林园偏好 → "高 ROE/垄断消费医药" → 已有 fscore/quality 覆盖，查正交
  - 陈小群席位 → "银河大连黄河路上榜后 N 日收益" → 龙虎榜因子（lhb_jg_cnt_20 已入池）
  - 游资接力 → "连板后换手承接" → 涨停族（limup_ex_5 已入池）
- ⚠️ 必须先查与池内锚点相关性（>0.5 即同构，无增量）

### Step 4 验证链（强制，与 factor-mining-workflow 同标准）
- 截面 ICIR → 去重闸门 → 组合层 T+1（验收 v1）→ 分年度 + holdout
- **重点核查**：席位/持仓披露时点的前视风险（T+1 披露 = 信息滞后，收益窗口必须对齐披露日）

### Step 5 结论分级
| 分级 | 含义 |
|---|---|
| ✅ 可入池 | 组合层通过 + 无前视 + 正交 |
| 🟡 观察 | 截面强但组合层弱/披露滞后 |
| ❌ 证伪 | 组合层负/同构/前视 |
| ⚠️ 造神预警 | 仅媒体热度无行为证据 |

## 三、批判与风险视角（本 skill 的独特价值）

1. **造神机制**：交易软件龙虎榜推送 + 短视频发酵 + 跟风买入 = "互联网战法"利益链（媒体已调查披露）——**上榜≠能力，可能是收割工具**
2. **信息滞后**：季报持仓滞后 1-3 个月；龙虎榜 T+1；股东户数滞后——**你能看到的牛散操作，市场早已定价**
3. **幸存者偏差**：被媒体记住的都是 20 倍赢家，同批失败的无人知晓
4. **与工作区证伪知识呼应**：追高/打板/连板接力在组合层多次证伪（limup_ex_5 需非一字板过滤、pitch 集中持仓 -60% 回撤）
