# 接入 AI API 后的一键部署指南（面向用户）

> 你刚下载了 DeepSeek HARNESS Quant 开源包。本指南带你从"空目录"到"系统跑通"。
> **核心逻辑：先接入 AI 的 API，剩下的事情（数据源接入、配置、验证）让 AI 一步一步带你做。**

---

## 第 1 步 · 环境准备（5 分钟，无需 AI）

```powershell
# 1. 确认 Python ≥ 3.11
python --version

# 2. 安装依赖
cd <解压目录>
pip install -r requirements.txt

# 3. 确认 Node.js ≥ 18（AI 控制台需要；无则 HARNESS 跳过、量化系统照常）
node --version
#    若无：https://nodejs.org 安装
```

> 注意：AI 控制台（HARNESS）只在**完整包（zip）**里集成；单文件 exe 不含 HARNESS。

## 第 2 步 · 接入 AI API（拿到 Key）

1. 打开 https://platform.deepseek.com/api_keys 创建 Key（形如 `sk-xxxxxxxx…`）
2. 复制凭据模板并填入：

```powershell
copy harness\home\.credentials.yaml.example harness\home\.credentials.yaml
# 编辑 .credentials.yaml：
#   DEEPSEEK_API_KEY: sk-你的key
```

3. 启动系统：

```powershell
python launcher.py
# 浏览器打开 http://127.0.0.1:8787/control
```

> 说明：API Key 只写在你本机的 `.credentials.yaml`（已被 gitignore 保护），系统会显示为 `sk-…尾4位`，不会回显全文。

## 第 3 步 · 让 AI 帮你一键部署（对话触发）

打开控制页（或 HARNESS 对话），对 AI 说：

```
一键部署
```

AI 会启动「一键部署向导」，**一步一步问你必需的东西**（每步一个主题，你答完才进下一步）：

| 步 | AI 会问 | 你要给的 |
|---|---|---|
| 0 | 环境自检（自动） | 无（自动查 Python/依赖/目录） |
| 1 | AI API 是哪个平台 | DeepSeek 官方 / 兼容 OpenAI / 暂不接入用演示模式 |
| 2 | 行情数据源 | ①Tushare（要 token，覆盖最全）②AKShare（免费免 token）③演示数据（立即可用） |
| 3 | 配置落盘（自动） | 无（AI 写入本地配置，不碰模板） |
| 4 | 拉取数据（自动） | 无（按所选源运行，失败会退回对应步骤重问） |
| 5 | 全链验证（自动） | 无（数据/看板 200/演示因子/生成报告） |
| 6 | 完成汇报 | 无（汇总接入内容与下一步建议） |

## 第 4 步 · 验证你的系统跑通了

- 看板 http://127.0.0.1:8787/ 正常打开，各页面 200
- 决策页能看到 Pitch 候选卡（用演示数据时数量有限，属正常）
- 部署报告：`logs/deploy_report.md`

## 常见问题

| 问题 | 处理 |
|---|---|
| 控制页显示"HARNESS 暂不可达" | 确认 HARNESS（:3080）已启动；控制页会自动重连（2 秒一次） |
| Tushare token 无效/积分不足 | 回到第 2 步换 AKShare 或演示数据；部分接口需积分，AI 会提示覆盖限制 |
| 换手率历史缺失 | 属数据源边界（2019 前无换手数据），系统已按口径处理 |
| 想接入分钟数据 | 见《分钟数据接入说明.md》（私有数据源，需自行获取） |
