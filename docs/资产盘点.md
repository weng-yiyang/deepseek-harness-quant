## 2. 风控系统（七道防线）

### 2.1 风控引擎（risk/）七道防线

| 道 | 防线 | 说明 |
|---|---|---|
| 1 | 数据审计 gate | `data_audit.py`：完整性门槛（≥4000 只）、单位归一、PIT 对齐、覆盖率分年核查——数据不过关全链停机 |
| 2 | 因子健康 | ICIR 滚动 + 衰减预警 + 反向漂移监控（见 §5），失效因子自动降级/剔除 |
| 3 | FRC 相关性排雷 | 家族归并（3 年 Spearman，|ρ|≥0.5 归一族）——防"多因子交叉确认"的共线性放大 |
| 4 | Beneish M-Score | 财务造假排雷，8 指标全量（5501 只：HIGH 260 / WATCH 350 / LOW 4891），HIGH 一票否决 |
| 5 | 竞价/开盘排雷 | 高开放量 → 减分/回避（反信号防守，不做买入信号） |
| 6 | 单因子依赖警示 | 仅 1 因子/单类型命中 → 橙徽章，需主观复核 |
| 7 | 归因门控（L0） | 防御期（择时<40）revalue/tech_sentiment 买入硬拒绝 403；下跌日放大亏损的类型从严 |

### 2.2 类型定制止损（stop_matrix v2）

| 类型 | 止损方案 | 实证依据 |
|---|---|---|
| breakout 突破 | 10% 硬止损（保留） | 硬止损是正资产：夏普 0.81→1.39，回撤 -29%→-8% |
| reversal 反转 | 删硬止损，改 ATR 3× + 时间止损 | 硬止损猎杀率 40%（假止损） |
| pv_consensus 量价共识 | 无硬止损，逻辑止损（共识瓦解） | 硬止损摧毁策略：夏普 0.40→-1.38 |
| quality_gap 质量折价 | 无硬止损，逻辑止损（质量破位） | 硬止损摧毁：夏普 0.65→-0.89 |

> 关键结论：**纪律 ≠ 普适安全垫**。防守型策略的硬止损是收益杀手，真正安全垫是"无硬止损 + 逻辑失效止损 + 基本面排雷"。附猎杀率监控（止损后 20 日反弹>2% = 假止损，>30% 触发重设计）。

### 2.3 假信号排雷层（fake_signal_flags，一票否决）

一字板（不可买）、高换手涨停诱多、天量滞涨、对倒疑似、接飞刀（超跌）、无量突破——6 类假信号 flag，命中即剔除。

## 4. 因子入池流程（端到端演示：研究散户情绪）

### 4.1 九步入池验证链

```
定域 → 生成 → ICIR初筛 → 去重闸门 → 组合层T+1 → 分年度holdout → 正交性 → 容量 → 归档
```

### 4.2 端到端演示：用户想研究"散户情绪的量化"

**第 1 步 · 自然语言指令（驱动层）**
用户在控制页对 AI 说："我想研究散户情绪的量化因子。"

**第 2 步 · LLM 拆解为可验证假设**
LLM 不直接荐股，而是把意图翻译成 4 条可证伪假设：

```
H1  散户关注度高的股票跑输      → 热度板块因子
H2  散户持有集中的股票跑输      → 股东户数变化因子
H3  散户情绪指标可择时          → 市场级散户情绪择时
H4  散户冷门反而跑赢            → 低换手因子（turn_low）
```

**第 3 步 · 生成因子公式（执行层）**
LLM 用 AlphaGPT 公式语言生成，或按 `factor_{name}` 命名规范手写注册：

```python
# factors/ 下注册，命名规范即接入（零改映射表）
def factor_retail_hot(df):      # H1 热度
    return rolling_corr(amount, circ_mv, 20)

def factor_retail_hold(df):     # H2 户数
    return gdhs_holder_chg(df)

def factor_turn_low(df):        # H4 低换手
    return -turnover_rank_20(df)
```

**第 4 步 · 注册即自动体检（执行层）**
`factor_{name}` 注册后自动进入：计算 → 入面板 → 入体检 → 入分发，无需改任何映射表。

**第 5 步 · 九步验证裁决（事实层，写死引擎说话）**

| 假设 | ICIR 初筛 | 组合层 T+1 | 分年度 | 裁决 |
|---|---|---|---|---|
| H1 热度板块 | 负 + 前视 | — | — | **证伪**（方向反 + 前视，作废） |
| H2 股东户数 | 弱/负 | 无效 | 2024+ 弱正=样本段效应 | **负结论**（不推广） |
| H3 散户情绪择时 | 无效 | — | — | **证伪**（回归 regime 框架） |
| H4 低换手 turn_low | 强 | +15.95%/-8.7%/1.11 | 2019+ 全正，2022 熊市 +6.7% | **入池**（唯一干净防守 alpha） |

**第 6 步 · 结论**
散户情绪维度最终以 **H4 反向冷门（turn_low）** 落地入池，H1/H2/H3 全部证伪并公开留档。

> 这就是本系统与"AI 荐股"的本质区别：**AI 只负责提出假设，写死的引擎负责验证，数据负责裁决。** 一条自然语言指令 → 4 条假设 → 3 条证伪 1 条入池，全程可复现、可审计。

## 5. 因子动态系统

因子不是"入池即永恒"，而是一套**实时健康监控 + 自动复检 + 拥挤治理**的生命周期管理。

### 5.1 实时健康监控（factor_health）

```
每日增量：20/60/120 日 RankIC + 252 日滚动 ICIR + 短期衰减预警
状态机：  ✅有效  ⚠️衰减  ⚠️反向漂移  ❌失效  🟡数据不足
```

- 反向漂移：因子注册方向与当前 IC 符号相反 → 预警主系统核对（历史：20 个因子方向修正 + flip WARNING 机制）
- 衰减预警：turn_mid_prox 近 60 日 IC 0.041 vs 历史 0.090 → 预警走弱

### 5.2 注册即体检（auto_check）

- 扫注册表 vs 报告目录 → 未体检因子自动全量回测
- `--stale 90` 天过期复检——长期未验证的因子自动重跑

### 5.3 拥挤度监控（crowding）

- 60 日波动率分位 >90% 降权 / >95% 暂停——防止因子被市场挤兑

### 5.4 家族归并（共线性治理）

- 3 年 727 截面 Spearman，|ρ|≥0.5 归一族，同族只计 1 票（防重复计票）
- FDR BH q=0.05 多重比较校正——区分"真显著"与"多重检验的假显著"

### 5.5 中性化复核

- 行业/市值双中性后 IC 复核——区分"真 alpha"与"风格暴露"（shebao_chg 双中性 1.43→0.07、max_ret20 0.56→0.10 归零实证）

## 7. 为什么区别于其他 AI 炒股系统

| | 其他 AI 炒股系统 | DeepSeek HARNESS Quant |
|---|---|---|
| AI 角色 | 直接荐股 / 预测股价（黑箱） | 只驱动：控制 / 挖因子 / 审计 / 蒸馏（不预测） |
| 决策来源 | 模型输出（不可复现） | 写死引擎的确定性计算（可复现） |
| 验证 | 无（信模型） | 九步验证 + T+1 + 分年度 + 覆盖率（信数据） |
| 红线 | — | AI 不预测个股 |

> **语言模型是大脑，量化引擎是手，数据系统是事实。** AI 的想法永远先被写死的引擎检验，再用数据说话。
