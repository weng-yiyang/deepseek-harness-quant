## 二、使用流程（用户操作 1 分钟 + 系统自动）

1. **用户**：把网盘下载的数据（可任意格式/嵌套目录）放入
   `data/minute/download/`（百度/夸克客户端下载到这个目录即可）
2. **系统**：运行 `python data/ingest_minute.py --scan`（或每日自动调度）→
   自动解析（格式自适应：列名/编码/压缩包）→ 入库 `minute.db` → 更新 meta
3. **查询**：`--status` 查看入库进度；表 `minute_1m`（code, trade_time, OHLC, volume, amount, source）

## 三、入库规范

```
minute.db
├── minute_1m(code TEXT, trade_time TEXT, open/high/low/close REAL,
│             volume REAL, amount REAL, source TEXT,
│             PRIMARY KEY(code, trade_time))        -- 主键防重复
└── bar_meta(source, code, start_time, end_time, rows, updated_at)
```

- **source**：`a_share`（带 .SZ/.SH 后缀） / `futures`（品种+合约如 rb2610）
- **格式自适应**：自动探测列名（time/trade_time、vol/volume、ts_code/symbol/code 等）
  支持 .csv/.txt/.csv.gz；单股票文件无 code 列时用文件名推断
- **重复入库安全**：INSERT OR REPLACE，重跑不产生重复
