# 架构说明

## 总体数据流

```
数据源(Tushare/akshare/baostock)
   │  data/fetcher_*.py
   ▼
数据目录 bars.db / finance.db / ...      ← data/cache.py（唯一读取接口，主库+增量库合并）
   │
   ▼
因子引擎 factors/                        ← 打分/方向/健康
   │
   ├─▶ 机会扫描 scan.py --pitch          → Pitch 候选卡（评分/胜率/证据/止损）
   │        │
   │        ▼
   │   决策页 /pitch（人工审批 buy/drop）  ← 唯一买入指令来源（决策聚合）
   │
   ├─▶ 远期池 factors/opportunities/pitch_track.py
   │        ├─ 🅰 auto_pitch   自动入池（pitch_v2 全量）
   │        ├─ 🅱 machine_top01 机器强因子
   │        ├─ 🅲 human_select  人工选择
   │        ├─ 🅳 ai_select    AI 精选
   │        └─ ★ niu_select   牛散主观（按决策者分组）
   │        └─ update_fwd 每日滚动 T+1/5/20/60 收益验证
   │
   ├─▶ 策略层 strategy/ 组合构建（turn_low 防御主方案 + pitch 卫星）
   │        ▼
   │   风控 risk/（RiskAgent 六道 + 止损 6 规则 + 回撤三级）
   │
   └─▶ ETF 映射 etf/etf_map.py           → 策略暴露相关性 → ETF Pitch 卡 → 配置建议
             │
             ▼
        Web UI（deck/deck_server.py :8787 + ui_v2/）
```

## 核心模块

### 决策链（Pitch）

1. 每日收盘后机会扫描生成候选卡（`factors/opportunities/scan.py`）
2. 决策页人工审批（buy / drop），记录 `deck_decisions`
3. **买入指令 = L2 决策卡聚合**（同源，无两套推荐逻辑）

### 五池远期验证（主观多池）

所有入池标的（A/B/C/D/牛散）共享同一远期追踪机制：

- 入池时记录 `entry_date`（信号/决策日）+ `entry_close`
- `update_fwd()` 每日用 bars 更新 `fwd.t1/t5/t20/t60`（交易日偏移收益）
- `summary_by_pool()` 按池分组汇总（平均收益/胜率/样本数）；牛散池再按 **persona（决策者）** 分组
- 牛散决策链路：控制页对话 → 牛散回复最后一行结构化 JSON `{"niu_decisions":[...]}` → 自动入池（`pool_type=niu_select`，带决策者/决策时间/动作/理由/快照日期）

### 因子引擎

- 多因子打分 + 方向控制（`config/params.yaml` 的 `factors.direction`）
- 防御层：**turn_low（低换手）**——全市场 40 日 top20 等权，T+1，无止损无择时（2019-2026 实证年化约 +16%，回撤约 -9%）
- T+1 纪律：信号日收盘选股 → 次日开盘执行

### ETF 映射（配置表达层）

- 策略组合（turn_low）日收益 vs 候选 ETF（宽基/风格/行业/跨境/商品/债券）日收益
- 相关性检验：pearson 全期 + 年度 + 滚动 60 日（均值/末值/波动）+ beta + ETF 间相关矩阵（>0.85 去冗余）
- ETF Pitch 卡：匹配×稳定×流动 → A/B/C 档
- 小资金配置：高分互不冗余子集 → 等权/相关加权/相关×流动加权，输出复制组合与复制度
- 定位：**策略暴露的 ETF 表达/防御风格参考**，不是买入指令来源

## 目录

| 目录 | 职责 |
|---|---|
| `data/` | 数据层（缓存唯一接口、获取脚本、demo） |
| `deck/` | Web 服务（HTTP 路由、API、看板） |
| `factors/` | 因子引擎、机会扫描、Pitch、远期池 |
| `strategy/` | 组合构建、仓位、止盈止损 |
| `risk/` | RiskAgent、止损规则 |
| `backtest/` | 回测引擎 |
| `etf/` | ETF 映射 |
| `ui_v2/` | 前端页面 |
| `validation/` | 验证/审计 |
